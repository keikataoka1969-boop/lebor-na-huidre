# ダン・カウの書 物語集

『レヴァル・ナ・フイドレ（ダン・カウの書, Lebor na hUidre）』所収の物語を、中世アイルランド語の原典から日本語に訳した読み物集です。

- 公開ページ：https://keikataoka1969-boop.github.io/lebor-na-huidre/
- 収録：第一話「クアルンゲの牛捕り（Táin Bó Cúailnge）」全二十五章（写本の欠損まで）、第二話「ブリクリウの饗宴（Fled Bricrenn）」全十七章（写本の欠損まで）、第三話「ダ・デルガの館の崩壊（Togail Bruidne Da Derga）」全二十章（冒頭の欠損のあとから）、第四話「クー・フリンの病（Serglige Con Culaind）」全十四章、第五話「マール・ドゥーンの航海（Immram curaig Máele Dúin）」全十九章（写本の欠損まで）、第六話「エーダインへの求婚（Tochmarc Étaíne）」全十二章（前後に欠損）、第七話「コンラの冒険（Echtra Condla）」、第八話「クー・フリンの霊の戦車（Siaburcharpat Con Culaind）」全七章

底本：R. I. Best and Osborn Bergin (eds), *Lebor na hUidre: Book of the Dun Cow* (Dublin: Royal Irish Academy, 1929)／CELT: Corpus of Electronic Texts, G301900

訳と注は専門家の校閲を経ていない試訳です。
